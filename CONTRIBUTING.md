# Contribuire a RegBrain

Per persone e agenti valgono le stesse [istruzioni obbligatorie](AGENTS.md).

Prima di iniziare: [stato](docs/memory/STATE.md), [roadmap](roadmap.md), [decisioni](docs/memory/DECISIONS.md). Prima di consegnare: aggiungere il [registro della modifica](docs/memory/TEMPLATE.md) nella stessa pull request e seguire i [controlli della memoria](docs/memory/README.md).

Se uno strumento, incluso Lovable, non carica automaticamente le istruzioni, forniscigli AGENTS.md e chiedigli esplicitamente di seguirlo. La sincronizzazione automatica del codice non sostituisce l'aggiornamento della memoria. Usare branch e pull request; non usare push diretti su main come scorciatoia.
